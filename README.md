# Big Bang Challenge

## Description

This Java program iterates through numbers from 1 to 100 and generates an array based on the following rules:

- Numbers divisible by 3 are replaced with `BIG`.
- Numbers divisible by 5 are replaced with `BANG`.
- Numbers divisible by both 3 and 5 are replaced with `BIGBANG`.
- Other numbers remain as their original value.

The generated result is saved into `output.json`.

## Requirements

- Java JDK
